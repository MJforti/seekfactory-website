# SeekFactory — Verified Industrial Machinery Marketplace & Technical Audit Platform

> **Live Platform:** [SeekFactory](https://seekfactory.com/) | **Deployment:** Vercel

SeekFactory is India's premier B2B cross-border marketplace and technical audit platform connecting Indian SMEs and enterprise manufacturers directly with 50-point audited international machinery builders.

---

## 🏭 Core Features

- **Full-Screen Dark Industrial Editorial Aesthetic**: Built with a deep charcoal obsidian palette (`#090B0E`), slate card surfaces (`#181C24`), industrial machinery safety orange (`#E65100`), and audit gold badges (`#D97706`).
- **Autoplay Full-Width Hero Machinery Video**: Full-bleed background video featuring authentic heavy industrial factory and metal cutting operations.
- **Filterable Machinery Catalog**: Interactive inventory filtering across CNC Machining Centers, High-Power Fiber Laser Cutters, CNC Press Brakes, Servo Plastic Injection Molding, and CMM Quality Inspection Labs.
- **Quick Specs Modal & Product Detail Pages**: High-resolution image gallery, certified technical parameter tables, key feature checklists, industrial application mapping, and downloadable PDF datasheet simulator.
- **50-Point Foreign Factory Audit & BIS Regulatory Compliance**: Structured framework covering entity verification, machine tooling capacity, pre-shipment FAT testing, and Indian Bureau of Standards (BIS) customs clearance facilitation.
- **B2B Quotation Flow (RFQ)**: Itemized quotation request form allowing buyers to specify machine types, required quantities, target lead times, drawing uploads (CAD/STEP), and automated RFQ tracking IDs (`RFQ-SF-XXXXXX`).
- **Dual-Presence Infrastructure**: Regional sales & engineering desks in **Mumbai HQ & Delhi NCR (India)** coupled with physical audit centers in **Guangzhou & Changzhou (China)**.

## 🛠️ Technology Stack

- **Frontend Framework**: [React 18](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS Design Tokens (Custom Editorial Utility System)
- **Typography**: `Inter` (Sans-Serif Editorial Body) & `JetBrains Mono` (Technical Parameters)

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MJforti/seekfactory-website.git
   cd seekfactory-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
